# Tasks Dashboard

A modern React + TypeScript dashboard for managing and visualizing user data with inline editing, validation, and real-time state management.

    
# Project Setup
    npm install
    npm run dev

# Features
 - User management (Add, Edit, Delete)
 - Inline row & cell editing
 - Form validation using Zod
 - Global search & column filtering
 - Dashboard statistics (active, inactive, departments, roles)
 - Paginated data table with sorting
 - Zustand state management
 - Clean UI with Tailwind CSS & shadcn/ui


# Tech Stack
    Next.js (App Router)
    React + TypeScript
    Zustand (State Management)
    TanStack Table
    Zod (Validation)
    Tailwind CSS + shadcn/ui
    Data Model

# Each user includes:

    Name, Email, Phone
    Department & Role
    Status (Active / Inactive / On Leave)
    Salary
    Created Date
    Dashboard Overview

# Shows real-time stats like:

    Total users
    Active / inactive / on-leave users
    Department count
    Payroll & Avg Salary
    Role distribution

# Purpose
 Built to demonstrate advanced table handling, reusable UI components, and state-driven dashboard design in React.
